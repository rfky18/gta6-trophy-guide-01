Leonida Ledger — an offline guide and tracker for all 55 GTA VI trophies on PlayStation 5: every trophy with its official name, description and grade, a guide in our own words that cites its sources, a roadmap to the platinum (S0–S7), missable flags built from the official descriptions, a checklist saved in the browser with export and import, filters by kind, search, sort, per-trophy progress counters, and a spoiler setting that hides story trophies until earned. 55/55 guides cite a source; 174/174 steps cited; 7 sources read 20 Nov 2026.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. The app is static files under `app/` and works with the network off.
